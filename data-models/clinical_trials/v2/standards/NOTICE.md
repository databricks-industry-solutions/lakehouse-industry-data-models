## Standards Crosswalks

The crosswalk CSV files in this directory are derived from machine-readable standards specifications and the clinical_trials model.

### Source Specifications

#### CDISC SDTM and COSMoS

- **Repository**: https://github.com/cdisc-org/COSMoS
- **Commit**: 031429b
- **License**: MIT
- **Purpose**: CDISC SDTM dataset specializations and biomedical concepts
- **Attribution**: Clinical Data Interchange Standards Consortium (CDISC)

#### CDISC USDM (DDF-RA v4)

- **Repository**: https://github.com/cdisc-org/DDF-RA
- **Commit**: aa303cb
- **License**: MIT
- **Purpose**: Data Definition File - Regulatory Affairs with USDM schema and class definitions
- **Attribution**: Clinical Data Interchange Standards Consortium (CDISC)

#### HL7 FHIR

- **URL**: https://www.hl7.org/fhir/
- **Versions**: R4, R5
- **License**: CC0 1.0 Universal (Public Domain)
- **Purpose**: ResearchStudy, ResearchSubject, AdverseEvent, Observation, MedicationStatement, Condition, Patient resources
- **Attribution**: HL7 International

#### OHDSI OMOP CDM

- **Repository**: https://github.com/OHDSI/CommonDataModel
- **Commit**: 4a91030
- **License**: Apache License 2.0
- **Purpose**: Observational Medical Outcomes Partnership Common Data Model v5.4 field specifications
- **Attribution**: Observational Health Data Sciences and Informatics (OHDSI) initiative

#### FDA Sentinel Common Data Model

- **URL**: https://www.sentinelinitiative.org/
- **License**: Public Domain
- **Purpose**: FDA Sentinel program common data model for adverse event reporting
- **Attribution**: U.S. Food and Drug Administration (FDA)

#### PCORnet Common Data Model

- **URL**: https://pcornet.org/pcornet-common-data-model/
- **License**: Public Domain
- **Purpose**: Patient-Centered Outcomes Research Network (PCORnet) common data model

## Crosswalk Generation

The crosswalk CSVs are generated by the `generate_crosswalks.py` tool, which applies curated mapping rules defined in `rules/clinical_trials.csv`.

- **Generator**: Python 3 (stdlib only)
- **License**: Applies to the generated artifacts and rules
- **Attribution**: Databricks Industry Data Models Contributors

## Usage and Attribution

When using these crosswalks in your work:

1. Acknowledge the sources of the underlying standards (listed above)
2. Note that mappings are maintained by the Databricks Industry Data Models project
3. Respect the individual license terms of each standard (primarily MIT and CC0)

Example attribution:

> Clinical data mappings derived from CDISC SDTM (MIT), CDISC DDF-RA v4 (MIT), HL7 FHIR R4 (CC0), OHDSI OMOP CDM v5.4 (Apache 2.0), FDA Sentinel CDM, and PCORnet CDM via the Databricks Industry Data Models project.

## No Licensed Dictionary Content

These crosswalks reference but do not include:

- MedDRA (Medical Dictionary for Regulatory Activities) - proprietary, owned by MSSO/IFPMA
- WHODrug (World Health Organization Drug Dictionary) - proprietary, owned by WHO
- SNOMED CT (Systematized Nomenclature of Medicine Clinical Terms) - proprietary, owned by SNOMED International

References to these dictionaries (e.g. "meddra_pt_code") are descriptive only and comply with fair use and attribution requirements. Licensed dictionary content (terms, codes, hierarchies) is never embedded.
